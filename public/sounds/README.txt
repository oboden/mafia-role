Drop the reveal sounds here (mp3, m4a, ogg or wav):

  buildup.mp3   plays while a player holds their card (about 1.2 seconds; it is cut off at the reveal)
  reveal.mp3    plays when the card opens

Every role hears the same two sounds, so nobody at the table can tell who's who.
Until these files exist, quiet placeholder tones play instead.

This repository is public: only add sounds whose licence allows redistributing the file
itself (CC0 is safest, e.g. Kenney.nl or Freesound with the CC0 filter).
